# 💻 ICT Task & Project Manager | สพม.พัทลุง

ระบบบริหารจัดการโครงการและภารกิจงานประจำตัว (**Personal Project & Task Management System**) สำหรับ **นักวิชาการคอมพิวเตอร์ สำนักงานเขตพื้นที่การศึกษามัธยมศึกษาพัทลุง (สพม.พัทลุง)**

ออกแบบในรูปแบบ **Responsive Single-Page Application (SPA)** รองรับทั้งการใช้งานบนคอมพิวเตอร์ (Desktop/Laptop) และสมาร์ทโฟน (Mobile Browser) เชื่อมต่อกับฐานข้อมูล **Google Sheets** ผ่าน **Google Apps Script API (`Code.gs`)** พร้อมระบบแจ้งเตือนสรุปภารกิจประจำวันผ่าน **Telegram Bot API** อัตโนมัติทุกเช้าเวลา **07:30 น.**

## ✨ ฟีเจอร์หลักของระบบ

1. **ข้อมูลครบถ้วนตามโครงสร้างงาน ICT สพม.พัทลุง:**
   - **ประเภทงาน (5 ประเภท):** โครงการ/กิจกรรม, งานประจำ, งานอีเว้นท์, งานนอก, งานแทรก/งานด่วน
   - **หมวดหมู่เรื่อง/รายการ (23 หมวดหมู่):** ครอบคลุมตั้งแต่ `01. งาน Network Administrator` จนถึง `99. งานอื่นๆ ที่ได้รับมอบหมาย` พร้อมช่องพิมพ์ค้นหาหมวดหมู่ได้อย่างรวดเร็ว
   - **กลุ่มงานและโรงเรียนในสังกัดครบ 100%:** เลือกได้ทั้งกลุ่มงานภายใน สพม.พัทลุง (12 กลุ่ม/ภาพรวม) และโรงเรียนมัธยมศึกษาในสังกัดทั้ง **27 โรงเรียน** (`93012001 - พัทลุง` ถึง `93012028 - อุดมวิทยายน`) แบบ Multi-Select Tag หรือพิมพ์เพิ่มเองได้
2. **คำนวณวันคงเหลือและแจ้งเตือนสถานะอัตโนมัติ (`remainingDays`):**
   - `เสร็จสมบูรณ์` (สีเขียว) เมื่อสถานะเป็น `"เสร็จแล้ว"`
   - `เลยกำหนด X วัน` (สีแดงกะพริบ) เมื่อเลยวันกำหนดส่ง
   - `ครบกำหนดวันนี้!` (สีส้มเข้ม) เมื่อถึงวันกำหนดส่งพอดี
   - `เหลือ X วัน (เร่งด่วน)` (สีเหลืองอำพัน) เมื่อเหลือเวลา 1–3 วัน
   - `เหลือ X วัน` (สีเทา/น้ำเงิน) เมื่อเหลือเวลามากกว่า 3 วัน
3. **3 มุมมองการทำงาน & กราฟวิเคราะห์ภาระงาน:**
   - **Table View** (ตารางจัดการข้อมูลสำหรับหน้าจอคอมพิวเตอร์)
   - **Card Grid View** (การ์ดงานพร้อมปุ่มเปลี่ยนสถานะด่วน เหมาะสำหรับมือถือ)
   - **Kanban Board View** (บอร์ด 4 คอลัมน์แยกตามสถานะงาน)
   - **Interactive KPI Cards & Priority Focus Zone:** คลิกที่การ์ด KPI ด้านบนเพื่อกรองงานด่วนหรืองานค้างได้ทันที
4. **ทำงานได้ทันทีแม้ยังไม่ต่ออินเทอร์เน็ต (Offline/Preview Smart Cache):**
   - ใช้ `localStorage` เป็น Smart Cache พร้อมข้อมูลจำลองเสมือนจริงของ สพม.พัทลุง ทำให้ทดสอบและใช้งานได้ทันที 100% ก่อนนำไปผูกกับ Google Apps Script จริง

## 🧪 1. วิธีรันการทดสอบระบบ (Pre-Flight Test) ก่อนนำขึ้นใช้งานจริง

ระบบมีชุดทดสอบความพร้อมอัตโนมัติ (**Pre-Flight Diagnostic Suite**) เพื่อตรวจสอบความถูกต้องของข้อมูลและลอจิกก่อนทำการ Git Push หรือ Deploy ทุกครั้ง:

### วิธีที่ 1: ตรวจสอบผ่านหน้าเว็บ UI
1. เปิดหน้าเว็บ `index.html` บนเบราว์เซอร์
2. คลิกปุ่มสีเขียว **`ตรวจสอบระบบ (Run Self-Test)`** บนแถบเมนูด้านบน
3. ระบบจะแสดงหน้าต่างผลการตรวจเช็คทั้ง 4 ด้าน (โครงสร้างข้อมูล 23 หมวดหมู่ / 27 โรงเรียน, การคำนวณวันคงเหลือ, การจำลอง CRUD ในโหมด Sandbox, และความพร้อมของ JSON/Telegram Payload)

### วิธีที่ 2: ตรวจสอบผ่าน Terminal (สำหรับนักพัฒนา / AI Agent)
รันคำสั่งต่อไปนี้ในโฟลเดอร์โปรเจกต์:
```bash
# 1. ตรวจสอบไวยากรณ์ของโค้ด (Syntax Check)
node -c app.js
node -c Code.gs

# 2. รันชุดทดสอบ Pre-Flight Test Suite อัตโนมัติ
node test-suite.js
```

## 🔄 2. วิธีเชื่อมต่อ Git Repository เพื่อให้ AI Agent (`Gemini in Antigravity`) Push โค้ดให้อัตโนมัติ

เวิร์กโฟลว์ของโปรเจกต์นี้ออกแบบให้ **AI Agent เป็นผู้เขียนโค้ด รันทดสอบ และสั่ง `git push` ขึ้น Git Repository ให้อัตโนมัติเมื่อคุณยืนยันผลการทดสอบ** ส่วนการกด Deploy ขึ้น Production จริงจะอยู่ในมือของคุณ 100%

### ขั้นตอนการตั้งค่า Git ครั้งแรก
1. สร้าง Repository ใหม่บน GitHub / GitLab (เช่น `sesao-ptl-ict-task-manager`)
2. เชื่อมต่อโฟลเดอร์โปรเจกต์เข้ากับ Remote Repository ของคุณ:
   ```bash
   git init
   git branch -M main
   git remote add origin https://github.com/<ชื่อผู้ใช้ของคุณ>/<ชื่อ-repo>.git
   ```
3. **วิธีสั่งให้ AI Agent ทำการ Push โค้ด:**
   - ทุกครั้งที่แก้ไขโค้ดเสร็จ AI จะรัน `node test-suite.js` และเปิด Local Preview ให้คุณตรวจสอบก่อนเสมอ
   - เมื่อคุณตรวจสอบแล้ว เพียงพิมพ์บอกในแชทว่า **`"ผ่าน"`**, **`"ยืนยัน"`**, หรือ **`"Push โค้ดเลย"`**
   - AI Agent จะรันคำสั่ง `git add . && git commit -m "..." && git push` (หรือรันสคริปต์ `push-code.bat`) เพื่อส่งโค้ดขึ้น Git ให้คุณทันที!

## 🚀 3. ขั้นตอนการติดตั้งใช้งานจริงบน Google Sheets & Google Apps Script (Manual Deploy)

### ขั้นตอนที่ 3.1: เตรียม Google Sheets และคัดลอกโค้ด `Code.gs`
1. เปิด [Google Sheets](https://sheets.new) สร้างสเปรดชีตใหม่ ตั้งชื่อเช่น **`ICT_Task_Database_สพม_พัทลุง`**
2. ไปที่เมนูด้านบน **ส่วนขยาย (Extensions)** > **Apps Script**
3. ในหน้าต่าง Apps Script:
   - คัดลอกโค้ดทั้งหมดจากไฟล์ [`Code.gs`](./Code.gs) ไปวางทับในไฟล์ `Code.gs` บน Apps Script
   - คลิกไอคอน ⚙️ **การตั้งค่าโปรเจกต์ (Project Settings)** ด้านซ้าย > ติ๊กถูกที่ **"แสดงไฟล์รายการ `appsscript.json` ในเครื่องมือแก้ไข"**
   - กลับไปที่หน้าเขียนโค้ด คลิกไฟล์ `appsscript.json` แล้วคัดลอกเนื้อหาจากไฟล์ [`appsscript.json`](./appsscript.json) ไปวางทับ (เพื่อตั้งค่า Timezone เป็น `Asia/Bangkok`)
   - กดปุ่ม 💾 **บันทึกโปรเจกต์ (Save)**

### ขั้นตอนที่ 3.2: สร้างตารางฐานข้อมูลและ Deploy เป็น Web App
1. บนแถบด้านบนของ Apps Script เลือกฟังก์ชัน **`setupDatabase`** แล้วกดปุ่ม **เรียกใช้ (Run)** (อนุญาตสิทธิ์การเข้าถึงให้เรียบร้อย) — ระบบจะสร้างชีต `Tasks` และ `Config` ให้อัตโนมัติ
2. กดปุ่มสีน้ำเงินมุมขวาบน **การทำให้ใช้งานได้ (Deploy)** > **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
3. เลือกประเภทเป็น ⚙️ **เว็บแอป (Web app)**:
   - **ดำเนินการในฐานะ (Execute as):** `ฉัน (Me)`
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access):** `ทุกคน (Anyone)`
4. กด **ทำให้ใช้งานได้ (Deploy)** แล้วคัดลอก **Web App URL** (ที่ลงท้ายด้วย `/exec`) เก็บไว้

### (ทางเลือกเสริม) การอัปเดตโค้ดผ่าน Google `clasp` CLI
หากต้องการใช้ `clasp` ช่วยส่งไฟล์ `Code.gs` ขึ้น Google Apps Script:
1. คัดลอกไฟล์ `.clasp.json.example` เป็น `.clasp.json`
2. นำ **Script ID** จากหน้า Project Settings ของ Google Apps Script มาใส่ใน `.clasp.json`
3. รันคำสั่ง `npx @google/clasp login` และ `npx @google/clasp push`

## 🤖 4. ขั้นตอนการตั้งค่า Telegram Bot แจ้งเตือนทุกเช้า 07:30 น.

1. **สร้าง Telegram Bot:**
   - เปิดแอป Telegram ค้นหา **`@BotFather`** แล้วพิมพ์คำสั่ง `/newbot`
   - ตั้งชื่อบอทให้เรียบร้อย คุณจะได้รับ **`Telegram Bot Token`** (เช่น `123456789:AAH...`)
2. **หาค่า Chat ID ของคุณ:**
   - ทักแชทไปหาบอทที่คุณเพิ่งสร้าง แล้วกด **Start** (หรือดึงบอทเข้ากลุ่มแจ้งเตือนของงาน ICT)
   - ค้นหาบอท **`@userinfobot`** หรือเปิด URL `https://api.telegram.org/bot<ใส่_TOKEN_ของคุณ>/getUpdates` บนเบราว์เซอร์เพื่อดูเลข **`chat.id`**
3. **ผูกค่าในหน้าเว็บ UI:**
   - เปิดหน้าเว็บ `index.html` > คลิกปุ่ม **`ตั้งค่าระบบ`** บนแถบเมนูด้านบน
   - วาง **Google Apps Script Web App URL**, **Telegram Bot Token**, และ **Telegram Chat ID** แล้วกด **บันทึกการตั้งค่า**
   - ทดสอบกดปุ่ม **`ทดสอบส่ง Telegram`** บนแถบด้านบน ระบบจะส่งข้อความสรุปภารกิจเข้ามือถือของคุณทันที!
4. **เปิดใช้งานแจ้งเตือนอัตโนมัติทุกเช้า 07:30 น.:**
   - กลับไปที่หน้า Google Apps Script Editor
   - เลือกฟังก์ชัน **`setupDailyTrigger`** จากเมนูด้านบน แล้วกดปุ่ม **เรียกใช้ (Run)** เพียงครั้งเดียว
   - ระบบจะสร้าง Time-driven Trigger เพื่อรันฟังก์ชัน `sendMorningTelegramDigest` ส่งสรุปงานด่วนและงานค้างเข้า Telegram ของคุณทุกวันเวลา **07:30 น.** โดยอัตโนมัติ
